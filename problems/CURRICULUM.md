# 코테 캠프 커리큘럼 설계표

목표: 코테 입문자 → **기업 코테를 볼 수 있는 수준** (백준 실버 상위~골드 하위, 프로그래머스 Lv2 중심, 카카오 1~4번, 삼성 SW 구현형).

- 단계: 입문 / 기본 / 응용. 주차 마지막 문제는 **마을 보스**(★).
- 시간으로 평가하는 문제는 없어요. 유형과 단계만 붙어 있고, 기록은 화면에 보이지 않아요.
- 문제 본문은 모두 새로 써요 (유명한 유형을 참고하되 시나리오·수치·제목은 새로 만들어요).
- 1~2주차는 **만들어져 있고 검증을 마쳤어요**. 3주차부터는 이 표대로 만들어요.
